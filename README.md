# RelayWorks AI Content Brain

## Project Structure

```text
main.py
agents/
tools/
memory/
```

## Mac Setup

1. Clone the repo.
2. Create `.env` from `.env.example`.
3. Add your API keys.
4. Create and activate a virtual environment.
5. Install requirements.
6. Run `python main.py`.

## Example Commands

```bash
cp .env.example .env
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```
